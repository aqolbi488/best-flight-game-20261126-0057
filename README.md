Kestrel Coast is a small island flight game: chase or cockpit views over coastline, patchwork fields, hills and a seaside town, with throttle/stall/turn discipline, fuel and hull management, a gold-ring circuit and a supply-drop mission, and a gentle runway landing to finish each sortie.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — W/S throttle, arrows/A/D steer and pitch, C switches camera, R restarts.
